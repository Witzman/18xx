## Rules Summary (§11.3.4–11.3.7, §11.1.6)

### Ferries (§11.3.7)
- Pre-printed blue track through sea hexes. Any train can ride.
- Each ferry has a distance number (oval). Counts against city limit. No revenue.
- If RR has token adjacent to ferry → same city-limit reduction benefit as port token.
- Ferry distance counts toward cross-water tile cost (£5 × distance, §11.1.6).
- Some ferries have towns on them (Danzig, §AE6). Town included in route,
  but full ferry distance still counts.
- If ferry end has port symbol → same hex side is a port arrow into adjacent sea zone.
- Ferries exempt from rule requiring land hex between sea crossings.

### Sea Crossings / Port-to-Port (§11.3.4)
- Sea crossing: route from one port to another via adjoining sea zones.
- Each sea zone traversed counts 1 against city limit. No revenue.
- Train enters/leaves sea zone via track section or offshore port connecting to
  blue "port arrow" in the adjacent sea zone.
- Between sea crossings, train must cross at least one land hex side
  (exception: ferries are exempt from this rule).
- Multiple sea crossings allowed per train run.
- Multiple trains from same RR may use same sea zone / ferry / port arrows.

### Port Types (§11.3.6)
- Public port: anchor in light-blue circle. Any train may use.
- Private port: anchor in red circle. Only RR with token in adjacent city may use.
- Offshore port: city has port access one or more hexes distant (river/fjord).
  Train connects directly to city — does NOT travel through intervening hexes.
  Does NOT use a track section from the city. City track has no effect.
- Edinburgh: private offshore port in North Sea (Firth of Forth hex blocks normal access).
- London: offshore port (multiple stations until brown tile; all connected to offshore port).
- Both stations on London tile connected to offshore port (§11.3.6 example).

### Port Authorities (§11.3.5)
- Majors only, one per major, £125, purchased during OR before Buy Trains.
- North Sea PA: all light-blue zones (N Atlantic, Silver Coast, Celtic, Biscay, Channel,
  North Sea, German Bight, Skagerrak, Baltic, Gulf of Finland).
- Mediterranean PA: all sea-green zones (Gibraltar, Balearic, Sardinia, Tyrrhenian,
  Adriatic, Aegean, Levantine, Black Sea, Karkinitsky Bay).
- Benefit: reduces sea zone count against city limit by 2 (per RR, not per train;
  can split between 2 trains).
- Also reduces cross-water tile/token costs by 2 sea zones.
- Port token: reduces zone count by 1 (Ph2–6) or 2 (Ph7–8) — per train individually.
- H Minor (GWS): reduces zone count by 1 (Ph2–6) or 2 (Ph7–8) — per RR.
- Star Harbor token: same benefit as port token.
- All reductions stack to minimum 0; cannot reduce ferry distance to negative.

### Cross-Water Tile Laying (§11.1.6)
- RR can lay tile on far shore if hypothetical train can reach via sea crossing.
- Fee: £5 × ferry distance (for ferry crossing) + £10 per sea zone crossed.
- Port authority reduces total sea zones + ferry distance counted by 2.
- Port tokens and H Minor do NOT reduce this cost.
- Nationals exempt from all tile placement costs.

## Architecture Decisions

### Routing Model — Option B (chosen 2026-05-29)

**Problem**: Port stubs are terminal dead ends. Engine routes by following physical
path connections. UI cannot draw a sea crossing route without physical paths.

**Solution**: Two-layer approach:

**Layer 1 — Sea hex path mesh (L1, map data)**
Add `path=a:0,b:3;path=a:1,b:4;path=a:2,b:5` (all-edges connected) to interior
sea zone hexes to create traversable mesh between stubs within each zone.
Province border hexes get same treatment but mark zone transition points.
This allows the UI to draw routes from any stub to any other stub in the zone.

Sea hexes that are NOT interior to any zone (border hexes with impassable edges)
get partial paths only on their open edges.

**Layer 2 — check_distance override (L2, game.rb)**
Override `check_distance` in game.rb to:
  1. Detect sea zone stubs in route path (hexes present in SEA_ZONE_FOR_HEX lookup)
  2. Count distinct sea zones traversed (each = 1 against city limit)
  3. Add ferry distances for ferry hexes traversed (FERRY_DISTANCES constant)
  4. Sum with normal check_distance for land stops

Build inverse lookup at setup:
  SEA_ZONE_FOR_HEX = SEA_ZONES.each_with_object({}) { |(zone, hexes), h|
    hexes.each { |hex| h[hex] = zone } }.freeze

**check_connected override (L2, game.rb)**
Override `check_connected` to allow stub-to-stub routing across zone boundaries
using zone adjacency graph derived from province borders.
(May be implicit once physical mesh is in place — evaluate after mesh.)

### Ferry Distance Counting
FERRY_DISTANCES = { 'AE6' => 1, ... }.freeze in game.rb.
check_distance sums FERRY_DISTANCES[hex.id] for each ferry hex in route.
Ferry distance counted separately from sea zone count (both apply to city limit).
